The method behind every prompt
  1. Don’t paste data into a chat. Ask the AI to read only the column headers, then write a script that runs on your own computer over every row.
  2. Have the script print only counts, totals and the names of the files it saves. The detail goes into a workbook you open yourself.
  3. Check every output against control totals: rows in equal rows out, and totals agree to the ledger or the source report.
  4. Keep a clean working folder per job, with copies of only the files that job needs. Originals stay untouched.
  5. Keep judgement with you. The script finds exceptions; you decide what they mean.

File names, columns, thresholds and names come from the books’ worked examples, where every company, person and figure is made up. Replace them with your own. Where a prompt depends on law, rates or thresholds, it asks the AI to use your own master file or the official text, not its memory.
